# Inventory Management System

A responsive inventory management web application built using React and JavaScript. It helps users monitor stock levels, manage inventory items, and track stock availability.

## Features

- Inventory overview dashboard with dynamic stock statistics.
- Add new inventory items.
- Edit existing inventory details.
- Adjust stock quantities.
- Search inventory by item name or ID.
- Filter items by category and stock status.
- Sort inventory records.
- View detailed item information.
- Responsive layout for desktop, tablet, and mobile devices.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- Vite

## Installation and Setup

1. Clone the repository:

   `git clone YOUR_REPOSITORY_URL`

2. Navigate to the project folder:

   `cd inventory-management`

3. Install dependencies:

   `npm install`

4. Start the development server:

   `npm run dev`

5. Open the local URL displayed in your terminal.

## Project Structure

- `src/App.jsx` – Main application and navigation.
- `src/App.css` – Main styling and responsive layout.
- `src/InventoryPage.jsx` – Inventory list and item details.
- `src/Inventory.css` – Inventory page styling.
- `src/AddItem.jsx` – Add and edit item form.
- `src/AddItem.css` – Form styling.

## Data Storage

This assessment uses mock inventory data and React state. No backend or database is required.
